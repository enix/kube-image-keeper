Settings

Properties of hosts and repositories, applied on every request whatever the rules. Objects are added and deleted, not edited; a user, a quota or the host auth of the same name or host is replaced.

Users

Accounts for Basic auth and Bearer tokens, valid on every host, proxies included. Passwords are shown in clear on purpose: kuik's pull secrets need them.

{{template "set-users" .}}

Grants

Give users pull, push or delete on a host and repository glob. A repository matched by a grant is restricted to the users of the matching grants; the others stay open.

{{template "set-grants" .}}

Host auth

Basic is the default. A Bearer host serves its own /token endpoint and challenges every request without credentials, like Docker Hub.

{{template "set-hostauth" .}}

Aliases

Rewrite a repository prefix when computing the content key, so an alternative on another path serves the same image (alt1/mirror/acme serves acme).

{{template "set-aliases" .}}

Divergents

Salt the content key of a host and repository glob: the same repo:tag serves other digests there.

{{template "set-divergents" .}}

Platforms

Narrow the synthetic images of a host and repository glob to some platforms (first match wins); their digests change.

{{template "set-platforms" .}}
platforms {{range platforms}} {{end}}

Quotas

A limit per window, counted per key (global, client ip or user), by default on manifest GETs. It applies through a rule with the quota effect; manifest answers of a rule with a quota carry RateLimit-Limit and RateLimit-Remaining.

{{template "set-quotas" .}}
kinds {{range kinds}} {{end}}
