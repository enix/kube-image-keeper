State

Export and import the rules and settings as YAML.

Export

Download the settings as YAML (rules, aliases, divergents, platforms, users, grants, host auth, quotas).

Sets

A set groups the objects one test or fixture created; deleting it removes them in one go. Merging adds the document's objects on top, tagged with the set; replacing loads the document as the whole settings.

{{template "sets" .}}

Import

Merge the YAML into a named set, or replace every rule and setting with it. A rejected import changes nothing.

Reset

Deletes every rule, setting, set, image, logged request and stat; with the box ticked, every repository of every proxy backend too. This cannot be undone.
